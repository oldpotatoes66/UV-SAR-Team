# F4HWN Bandscope v4.3 中文使用说明

适用设备：Quansheng UV-K5 / UV-K6 / 5R（DP32G030）

本文对应当前已刷入设备的 **F4HWN Bandscope v4.3**。

## 1. 功能用途

Bandscope 是一个简易频谱扫描与信号监测工具，可以：

- 在当前 VFO 或信道频率附近寻找活动信号；
- 显示不同频点的相对信号强度；
- 自动停在较强信号上监听；
- 进入单频详细监听，查看 RSSI、S 值和 dBm；
- 手动降低接收增益，辅助近距离无线电测向或“猎狐”。

它不是专业频谱仪，显示结果会受到天线、接收增益、附近强信号和 UV-K6 前端动态范围的影响。

## 2. 进入与退出

1. 正常开机。
2. 先在主界面选择要搜索的 VFO 或信道，并调到目标频率附近。
3. 短按 `F`。
4. 再按 `5 NOAA`，进入 Bandscope。
5. 在扫描画面按 `EXIT`，返回主界面。

当前 VFO/信道的接收频率通常作为频谱扫描的中心参考频率。

## 3. 频谱扫描画面按键

| 按键 | 功能 |
|---|---|
| `UP` / `DOWN` | 向上或向下移动扫描频段 |
| `1` / `7` | 增大或减小相邻频谱柱之间的频率间隔 |
| `2` / `8` | 增大或减小每次按上下键时的频谱移动步长 |
| `3` / `9` | 调整纵向强度刻度上限 |
| `4` | 切换频谱柱数量/扫描点数量 |
| `5` | 输入扫描起始频率；用 `*` 输入小数点 |
| `6` | 切换接收带宽 |
| `0` | 切换 FM、AM、USB 等解调模式 |
| `*` / `F` | 调整信号触发/静噪等级 |
| 侧键 1 | 将当前频率临时排除出本次频谱扫描 |
| 侧键 2 | 切换背光 |
| `PTT` | 进入最后接收或峰值频率的详细监听画面；在此处用于切换画面，不是正常发射操作 |
| `EXIT` | 退出 Bandscope，返回主界面 |

### 推荐的首次设置

- 不确定信号位置时，先使用较多扫描点和较大的频率间隔。
- 找到明显峰值后，逐步减小频率间隔并移动频谱，使峰值位于画面中间。
- 语音对讲机信号一般先使用 FM；航空 AM 信号使用 AM。
- 扫描范围过宽会降低刷新速度，测向时应尽量缩小到目标频率附近。

## 4. 详细监听画面

在频谱扫描画面发现目标峰值后，按 `PTT` 进入详细监听。

此画面用于固定监听一个频率，并显示信号强度。它也是 Bandscope 中最适合进行方向判断的画面。

| 按键 | 功能 |
|---|---|
| `MENU` | 依次选择 LNAs、LNA、PGA、IF 等接收参数 |
| `UP` / `DOWN` | 调整当前选中的接收参数 |
| `6` | 切换接收带宽 |
| `0` | 切换解调模式 |
| 侧键 1 | 切换连续监听/监测状态（原版行为） |
| 侧键 2 | 切换背光 |
| `EXIT` | 返回频谱扫描画面 |

再次回到频谱扫描画面后，按 `EXIT` 才会返回正常主界面。

## 5. 接收增益参数

在详细监听画面反复按 `MENU`，可选择以下项目，再用 `UP/DOWN` 调节：

| 项目 | 含义 | 实际用途 |
|---|---|---|
| `LNAs` | 前级短程/附加低噪声放大级 | 对弱信号灵敏度影响明显 |
| `LNA` | 低噪声放大器 | 远距离时提高灵敏度，近距离时应降低 |
| `PGA` | 可编程增益放大器 | 用于进一步控制接收链路增益 |
| `IF` | 中频相关增益/参数 | 用于细调强度响应和防止满表 |

不同项目的数值并不是可以直接相加的精确系统增益。猎狐时应关注调节前后信号条和 dBm 是否重新回到可比较范围。

### 增益使用原则

- 远距离、信号很弱：使用较高增益。
- 信号条长期顶满、转动天线看不出差异：逐级降低 LNA/PGA 等增益。
- 每降低一级增益后，重新缓慢转动天线一圈，寻找最强方向。
- 不要在不同增益设置下直接比较两次 dBm；先固定增益，再比较方向。

## 6. 猎狐/无线电测向操作流程

### 远距离搜索

1. 使用已知目标频率；若频率未知，先用 Bandscope 找到稳定峰值。
2. 使用全向天线确认信号存在。
3. 换用八木、环形天线或其他定向天线。
4. 进入详细监听画面。
5. 固定接收增益，缓慢转动天线一整圈。
6. 记录最强方向，并从另一个位置重复测量。

### 接近目标

1. 如果强度条满格或各方向差异很小，降低 LNA/PGA 增益。
2. 必要时换短天线、取下高增益天线，或使用外置衰减器。
3. 缩短每次移动距离，多次交叉测向。
4. 注意反射：建筑物、山体、车辆和金属设施可能产生错误峰值。

### 判断方向的小技巧

- 每次测量都保持天线高度和姿态一致。
- 旋转速度要慢，让显示有时间稳定。
- 不要只相信一次最大值；换位置后重复测量。
- 在复杂环境中，天线“最弱方向”有时比最强方向更尖锐、更容易判断。
- 若目标间歇发射，等待同一段发射期间再比较方向。

## 7. Scan Range 配合使用

在正常 VFO 频率模式下，长按 `5` 可进入 Scan Range 设置。设定扫描范围后，再进入 Bandscope，可以只观察指定频段。

适合：

- 已知目标只会出现在某个小频段；
- 附近存在大量无关强信号；
- 希望提高有效刷新速度。

范围不要设得过宽。先宽范围发现信号，再缩小范围精确观察。

## 8. 常见问题

### 按 PTT 后为什么没有正常发射？

在 Bandscope 扫描画面，PTT 被用来进入峰值详细监听。这是频谱功能的按键设计。需要发射时，应先完全退出 Bandscope 回到正常主界面。

### 信号条一直满格怎么办？

进入详细监听，按 `MENU` 选择 LNA/PGA 等项目并降低增益。仍然满格时，使用更短天线或外置衰减器。

### 频谱中有很多假峰怎么办？

缩小扫描范围、改变地点、降低增益，并检查是否有附近广播站、中继台或大功率发射机造成前端过载。

### dBm 数值是否绝对准确？

不应视为校准仪表读数。它更适合在频率、增益和天线条件不变时做相对比较。

### EXIT 的层级

- 详细监听画面按 `EXIT`：返回频谱扫描画面。
- 频谱扫描画面按 `EXIT`：返回正常主界面。

## 9. 安全与法规

- Bandscope 只能辅助判断信号，不能作为生命安全搜救的唯一手段。
- 不要在禁止发射的频率上发射。
- 搜救行动应同时使用地图、定位设备、通信计划和人员安全程序。
- 刷机、改装和扩大收发范围可能受当地法规限制。
- UV-K6 接收前端抗强信号能力有限，专业任务应配合合适的滤波器、衰减器和专业测向设备。
