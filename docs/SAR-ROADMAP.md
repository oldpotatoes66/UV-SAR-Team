# SAR 救援定位功能清单

本清单是 Quansheng UV-K6（DP32G030）SAR 固件的开发与验收依据。后续开发按优先级逐项完成，任何功能只有通过真机测试后才能标记为“已验证”。

状态说明：

- `[x] 已验证`：已在 UV-K6 / DP32G030 真机测试通过；
- `[~] 待验证`：源码和固件已生成，但尚未完成真机验收；
- `[ ] 未实现`：尚未开发或仍需重新设计。

## P0：基础定位能力

- [x] 已验证：`F + 5` 从主界面直接进入 SAR 模式；
- [x] 已验证：使用当前 VFO 频率作为目标频率；
- [x] 已验证：实时 RSSI/dBm 显示；
- [x] 已验证：0–100% 相对强度与大型强度条；
- [x] 已验证：IIR 平滑，减少数字跳动；
- [x] 已验证：`UP / DOWN / HOLD` 强度趋势；
- [x] 已验证：`HI / LOW / MIN` 三级自动接收增益；
- [x] 已验证：自动增益切换后显示连续性校正；
- [x] 已验证：SAR 模式锁定 PTT，避免误发射；
- [x] 已验证：`EXIT` 可退出并恢复射频状态；
- [x] 已验证：户外可读的大字界面与正确布局；
- [x] 已验证：SAR 内按 `MENU` 进入 Bandscope；
- [x] 已验证：Bandscope 按 PTT 锁定峰值并进入 SAR。

## P1：非专业人员快速判断

- [x] 已验证：声音强度提示，信号越强音调越高、间隔越短；
- [x] 已验证：数字键 `1` 或任一侧键切换 `BEEP / MUTE`；
- [x] 已验证：声音提示不会点亮红色发射灯；
- [x] 已验证：使用 BK4819 内部 `MUTE/BEEP` 切换，目标出现时可靠播放提示音；
- [ ] 未实现：进一步降低声音提示开启时的轻微模拟底噪，不得牺牲提示音可靠性；
- [x] 已验证：进入 SAR 后短暂显示 `CAL`，自动学习当前底噪；
- [x] 已验证：`TARGET` 表示当前检测到高于底噪的目标信号；
- [x] 已验证：`WAIT` 表示间歇信号刚停止，保留目标等待重发；
- [x] 已验证：`LOST` 表示等待超时，目标信号已丢失；
- [x] 已验证：连续达到近场阈值时显示 `TOO CLOSE`，并使用最高等级提示音；
- [x] 已验证：用醒目的箭头符号表示信号增强、减弱或稳定；
- [x] 已验证：显示 `PK` 峰值，SAR 中按 PTT 只重置峰值且不会发射；
- [ ] 未实现：按键操作后的短暂中文化或图形化提示，降低记忆负担。

P1 验收标准：弱信号、强信号、间歇信号和过载情况下提示必须稳定；静音、退出、自动增益和 PTT 锁定不得退化。

## P2：确认信号与减少误判

- [x] 已验证：数字键 `2` 开启智能监听窗口，仅在 `TARGET` 正在发射时播放语音；
- [x] 已验证：`WAIT/LOST` 期间保持静音，倒计时结束后自动恢复提示音模式；
- [x] 已验证：监听默认 10 秒，监听中再次按 `2` 可切换 20、30、5、10 秒并显示倒计时；
- [ ] 未实现：目标信号消失时保留最后一次强度和峰值；
- [ ] 未实现：提示多径风险，要求换位置再次测向；
- [ ] 未实现：强信号满量程时提示更换短天线或外置衰减器；
- [ ] 未实现：对不同频段、天线和机型进行 HI/LOW/MIN 阈值实测标定。

P2 验收标准：救援人员能快速确认信号内容，且不会因监听操作误发射、卡死或丢失目标频率。

## P4：未知频率快速发现（SAR-TEAM 完成后继续）

- [x] 已验证：可从 SAR 进入 Bandscope 手动寻找信号；
- [x] 已验证：可锁定扫描峰值并返回定位；
- [ ] 未实现：简化扫描向导，减少 Bandscope 专业参数；
- [ ] 未实现：窄、中、宽三档扫描范围；
- [ ] 未实现：按强度列出少量候选频率；
- [ ] 未实现：候选频率试听、确认、锁定；
- [ ] 未实现：排除持续载波、广播和明显干扰的简单规则；
- [ ] 未实现：扫描超时与“未发现信号”提示。

P3 验收标准：未受无线电训练的人员可按照屏幕提示，在少量按键操作内完成“扫描—确认—定位”。

## P3：队员防失联与 Yaesu ARTS 兼容（当前最高优先级）

目标机型：Yaesu VX-6R、VX-8R。该功能必须作为独立的 `TEAM LINK` 模式，不能在纯接收 SAR 测向模式中自动发射。

- [~] 待验证：只接收监听并识别 VX-6R 的 ARTS DCS 轮询；
- [ ] 未实现：只接收监听并识别 VX-8R 的 ARTS DCS 轮询；
- [~] 待验证：显示 `LINK OK / LINK WEAK / LINK LOST`；
- [~] 待验证：记录最后收到队友轮询的时间和 RSSI；
- [~] 待验证：兼容 25 秒轮询间隔；
- [~] 待验证：兼容 VX-6R 可选的 15 秒轮询间隔；
- [ ] 未实现：UV-K6 低功率发送约 1 秒 DCS 轮询；
- [ ] 未实现：与 VX-6R 双向 ARTS 真机互通；
- [ ] 未实现：与 VX-8R 双向 ARTS 真机互通；
- [ ] 未实现：连续约一分钟未收到轮询时发出失联警报；
- [ ] 未实现：恢复联系时发出不同的恢复提示；
- [ ] 未实现：锁定频率和 DCS 码，防止 TEAM LINK 运行中误改；
- [ ] 未实现：屏幕持续显示自动发射已启用，并提供一键退出；
- [ ] 未实现：发送功率、轮询间隔和提示音可配置；
- [ ] 未实现：可选呼号/CW 定时识别，满足当地法规和任务要求。

P5 分阶段验收：先只接收抓取 VX-6R/VX-8R 行为；确认识别可靠后才允许实验性自动回应；最后分别完成 UV-K6↔VX-6R、UV-K6↔VX-8R 双向测试。任何自动发射必须有醒目标识、低功率默认值、超时保护和明确退出方式。

- 当前真机验证基线：`SAR v3.4b`；
- 真机失败版本：`SAR v3.4c`，固定底噪导致环境噪声被持续误判为 `TARGET`；
- 状态验证版本：`SAR v3.4d`，`CAL / LOST / TARGET / WAIT / LOST` 顺序通过真机验证；
- v3.4d 已知问题：刚进入 SAR 时接收音频通道未关闭，第一次目标发射前有较大底噪；
- 真机失败版本：`SAR v3.4e`，进入 SAR 后安静，但关闭音频通道后 25 ms 提示音过短而无法听见；
- 真机失败版本：`SAR v3.4f`，音频建立时间已增加，但弱目标仍被旧的 20% 提示门槛静音；
- 真机失败版本：`SAR v3.4g`，已移除弱信号门槛，但物理音频通道关闭后仍无法可靠恢复提示音；
- 当前真机验证版本：`SAR v3.4h`，使用 BK4819 内部 `MUTE/BEEP` 切换，所有 `TARGET` 均可提示；
- v3.4h 已知限制：声音提示启用时存在轻微模拟底噪，但不再出现持续接收噪声；
- 真机失败版本：`SAR v3.5a`，近距离约 -67 dBm，但必须处于 MIN 档的条件导致提示未触发；
- 当前真机验证版本：`SAR v3.5b`，连续达到 -72 dBm 进入 `TOO CLOSE`，低于 -80 dBm 才退出；
- v3.5b 已完成单人双机台架测试：约 -67 dBm 可触发，减弱后可恢复，状态不闪烁；
- 待现场验证：双人远距离、不同天线、复杂地形和多径环境下的阈值与方向效果；
- 当前真机验证版本：`SAR v3.6a`，趋势箭头、PK 峰值、PTT 安全重置和显示布局均通过；
- 真机失败版本：`SAR v3.7a`，按 2 后无条件打开接收音频，目标未发射时背噪过大；
- 未刷机版本：`SAR v3.7b`，监听窗口内只在 `TARGET` 发射时打开语音；
- 当前真机验证版本：`SAR v3.7c`，智能监听、默认 10 秒、时间切换、自动静音和提示音恢复均通过；
- 当前构建固件区使用率约 98.9%，继续开发前必须先审计和压缩体积；
- 产品方向调整：优先制作 `SAR-TEAM`，简化扫描向导顺延；
- 下一步：建立 SAR-TEAM 精简构建，目标至少释放 4–6 KB；
- ARTS 开发顺序：只接收 VX-6R → 只接收 VX-8R → LINK 状态 → 低功率自动回应 → 双向互通。
- SAR-TEAM t0.1 已编译：`F + 6` 进入只接收模式，未配置数字亚音时自动使用 `D023N`；此版本绝不自动发射，等待 VX-6R 真机验证。
- 底噪优化列为后续项目，任何优化不得降低提示音可靠性。

## 每个版本的固定回归测试

每次刷入新固件都必须检查：

1. 正常启动，显示无乱码或错位；
2. `F + 5` 进入 SAR，频率正确；
3. dBm、百分比、强度条和趋势持续刷新；
4. 信号增强和减弱时方向提示正确；
5. HI/LOW/MIN 自动切换没有明显卡死；
6. `BEEP/MUTE` 可切换，声音随强度变化；
7. 提示音期间红色发射灯不亮；
8. PTT 在 SAR 中不会发射；
9. `MENU`、Bandscope 锁定和返回路径正常；
10. `EXIT` 可随时退出；
11. 重复进入和退出 SAR 后功能仍正常；
12. 失败时可用已验证的恢复固件重新刷写。

## 安全边界

- 本固件不是认证的生命安全设备，不能作为搜救行动的唯一定位手段；
- dBm 为相对参考，近距离或强信号过载时不是校准功率值；
- 建筑、车辆、山体和金属设施会产生多径，必须换位置交叉测向；
- 频率预设必须由当地任务负责人按法规和行动方案配置；
- 所有新功能先在低功率、短距离条件下测试，再用于野外训练。
