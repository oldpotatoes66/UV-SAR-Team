# SAR 救援定位功能清单

本清单最初是 Quansheng UV-K6（DP32G030）SAR 固件的开发与验收依据，当前也记录 UV-K1（PY32F071）独立移植状态。两个 MCU 系列使用不同二进制，禁止交叉刷写。任何功能只有通过对应机型真机测试后才能标记为“已验证”。

状态说明：

- `[x] 已验证`：已在 UV-K6 / DP32G030 真机测试通过；
- `[~] 待验证`：源码和固件已生成，但尚未完成真机验收；
- `[ ] 未实现`：尚未开发或仍需重新设计。

- [x] 已验证：`F + 5` 从主界面直接进入 SAR 模式；
- [x] 已验证：使用当前 VFO 频率作为目标频率；
- [x] 已验证：实时 RSSI/dBm 显示；
- [x] 已验证：0–100% 相对强度与大型强度条；
- [x] 已验证：IIR 平滑，减少数字跳动；
- [x] 已验证：`UP / DOWN / HOLD` 强度趋势；
- [x] 已验证：`HI / LOW / MIN` 三级自动接收增益；
- [x] 已验证：自动增益切换后显示连续性校正；
- [x] 已验证：SAR 模式锁定 PTT，避免误发射；
- [x] 已验证：`EXIT` 可退出并恢复射频状态；

- [x] 已验证：SAR 内按 `MENU` 进入 Bandscope；

## P1：非专业人员快速判断

- [x] 已验证：声音强度提示，信号越强音调越高、间隔越短；
- [x] 已验证：数字键 `1` 或任一侧键切换 `BEEP / MUTE`；
- [x] 已验证：声音提示不会点亮红色发射灯；
- [x] 已验证：使用 BK4819 内部 `MUTE/BEEP` 切换，目标出现时可靠播放提示音；
- [ ] 未实现：进一步降低声音提示开启时的轻微模拟底噪，不得牺牲提示音可靠性；
- [x] 已验证：进入 SAR 后短暂显示 `CAL`，自动学习当前底噪；
- [x] 已验证：`TARGET` 表示当前检测到高于底噪的目标信号；
- [x] 已验证：`WAIT` 表示间歇信号刚停止，保留目标等待重发；
- [x] 已验证：`LOST` 表示等待超时，目标信号已丢失；
- [x] 已验证：连续达到近场阈值时显示 `TOO CLOSE`，并使用最高等级提示音；
- [x] 已验证：用醒目的箭头符号表示信号增强、减弱或稳定；
- [x] 已验证：显示 `PK` 峰值，SAR 中按 PTT 只重置峰值且不会发射；
- [x] 已验证：TEAM 数字配置键操作后显示约 1 秒的大字反馈，降低记忆和误操作风险。
- [x] 已验证：K1 `F+6` 实际切换并保存发射功率，显示短时大字反馈，A/B 两个 VFO 在待机界面持续显示各自功率。

P1 验收标准：弱信号、强信号、间歇信号和过载情况下提示必须稳定；静音、退出、自动增益和 PTT 锁定不得退化。

## P2：确认信号与减少误判

- [x] 已验证：数字键 `2` 开启智能监听窗口，仅在 `TARGET` 正在发射时播放语音；
- [x] 已验证：`WAIT/LOST` 期间保持静音，倒计时结束后自动恢复提示音模式；
- [x] 已验证：监听默认 10 秒，监听中再次按 `2` 可切换 20、30、5、10 秒并显示倒计时；
- [ ] 未实现：目标信号消失时保留最后一次强度和峰值；
- [ ] 未实现：提示多径风险，要求换位置再次测向；
- [ ] 未实现：强信号满量程时提示更换短天线或外置衰减器；
- [ ] 未实现：对不同频段、天线和机型进行 HI/LOW/MIN 阈值实测标定。

P2 验收标准：救援人员能快速确认信号内容，且不会因监听操作误发射、卡死或丢失目标频率。

## P4：未知频率快速发现（已取消，不纳入精简固件）

- [x] 已验证：可从 SAR 进入 Bandscope 手动寻找信号；
- [x] 已验证：可锁定扫描峰值并返回定位；
- [—] 已取消：扫描向导、候选频率、干扰排除和扫描超时等现场辅助功能。项目保持简单，未知频率搜索使用独立设备或既有工具。

P3 验收标准：未受无线电训练的人员可按照屏幕提示，在少量按键操作内完成“扫描—确认—定位”。

目标机型：Yaesu VX-6R、VX-7R、VX-8R。该功能必须作为独立的 `TEAM LINK` 模式，不能在纯接收 SAR 测向模式中自动发射。

- [x] 已验证：只接收监听并识别 VX-6R 的 ARTS DCS 轮询；
- [x] 已验证：只接收监听并识别 VX-7R 的 ARTS DCS 轮询；
- [x] 已验证：只接收监听并识别 VX-8R 的 ARTS DCS 轮询；
- [x] 已验证：`LINK OK / LINK WEAK / LINK LOST` 状态与计时；
- [x] 已验证：显示收到轮询时的 RSSI 和最后接收计时；
- [x] 已验证：兼容 25 秒轮询间隔；
- [x] 已验证：兼容 Yaesu 可选的 15 秒轮询间隔；
- [x] 已验证：UV-K6 与 UV-K1 低功率发送约 1 秒 DCS 023N 轮询；默认关闭，必须长按 `3` 才启用；
- [x] 已验证：与 VX-6R 双向 ARTS 真机互通；
- [x] 已验证：与 VX-7R 双向 ARTS 真机互通；
- [x] 已验证：与 VX-8R 双向 ARTS 真机互通；
- [x] 已验证：连续约一分钟未收到轮询时发出失联警报；原单次低音已验证但野外不够醒目，下一版改为三连低音待验证；
- [x] 已验证：失联后恢复联系时发出不同的双高音恢复提示；
- [x] 已验证：进入 TEAM 时锁定频率和 DCS 码，防止运行中误改；
- [x] 已验证：屏幕持续显示 `TEAM AUTO TX`，`EXIT` 可退出并在轮询发射中立即中止；
- [x] 已验证：K5/K6 可在 TEAM 内配置 P1/P2/P3；K1 使用当前频道 L1–L5；两类机型均可配置 15/25 秒轮询间隔和 `BEEP/MUTE`；
- [x] 已验证：可选呼号/CW 定时识别；每机呼号由配置脚本写入，按 `5` 启用后首次约 3 秒发送，之后每 10 分钟发送；默认关闭且仅在 AUTO TX 中工作；
- [x] 已验证：TEAM 模式在 ARTS 后台运行时接收正常语音，并允许 PTT 发送带 DCS 023N 的语音；人工 PTT 优先于自动轮询，松开后恢复监听并顺延下一次轮询；
- [x] 已验证：TEAM 内长按 `F` 约 1 秒锁定/解锁数字配置键，显示 `LOCK`；PTT 和 `EXIT` 始终可用；
- [x] 已验证：低电量发射保护、失联期间每 60 秒重复三连低音、长按 `3`、按键大字反馈和 60 秒人工 PTT 超时。

P5 分阶段验收：先只接收抓取 VX-6R/VX-8R 行为；确认识别可靠后才允许实验性自动回应；最后分别完成 UV-K6↔VX-6R、UV-K6↔VX-8R 双向测试。任何自动发射必须有醒目标识、低功率默认值、超时保护和明确退出方式。

- SAR-TEAM t0.1 历史版本曾使用 `F + 6` 进入只接收模式；正式版改为长按数字 `6` 进入 TEAM，并恢复 `F + 6` 的功率切换功能。未配置数字亚音时自动使用 `D023N`。
- SAR-TEAM t0.1–t0.3 失败原因：默认索引误设为 6，实际码字是 D043N；t0.2/t0.3 又把该数值按十六进制显示为 023，造成屏幕与真实码字不一致。t0.4 已改为索引 0，并恢复八进制显示，真实收发码字与屏幕均为 D023N。
- SAR-TEAM t0.3 待验证：改用正常接收链路完整初始化 DCS 解码器，并增加 `RF NO DCS` 诊断状态以区分“收到载波但未匹配 DCS”和“完全未收到轮询”。
- SAR-TEAM t0.4 真机结果：DCS 023N 实际码字修正后，Yaesu 发射可由 `RF NO DCS` 正确转为 `LINK OK`；DCS 接收匹配链路验证通过。
- SAR-TEAM t0.5 已刷机待验证：最后一次有效 DCS 轮询约 60 秒后发出一次低音失联警报；随后再次收到有效轮询时发出双高音恢复提示。提示音仅走本机扬声器，播放后重新建立 DCS 接收链路，仍不启用任何自动发射。K5TOOL 报告写入大小 `0xEFA4`、可用刷写区使用率 99.85%，后续功能开发前必须先释放空间。
- SAR-TEAM t0.6 精简构建已通过基础真机回归：新增 `SAR_TEAM_BUILD=1`，关闭普通音量/RSSI 条、1750 Hz、手电筒、复制频道、普通收发计时和非必要 F4HWN 界面扩展；SAR 状态机静态专用于测向路径，不再链接完整 Bandscope 调度链。K5TOOL 使用 Bootloader 3.00.02 / Protocol V2 成功写入 `0xDAA0` 字节，报告刷写区使用率 91.09%，所有区块均为 `OK` 并最终显示 `Done`；相比 t0.5 释放 5,380 字节并剩余约 5.3 KB。该历史版本当时使用 `F + 6` 进入 TEAM，并已验证 DCS 023N 可触发 `LINK OK`；正式版已改成长按数字 `6` 进入 TEAM、`F + 6` 切换功率。精简版 SAR 内 `MENU` 不进入 Bandscope，行为符合设计。

## 每个版本的固定回归测试

每次刷入新固件都必须检查：

1. 正常启动，显示无乱码或错位；
2. `F + 5` 进入 SAR，频率正确；
3. dBm、百分比、强度条和趋势持续刷新；
4. 信号增强和减弱时方向提示正确；
5. HI/LOW/MIN 自动切换没有明显卡死；
6. `BEEP/MUTE` 可切换，声音随强度变化；
7. 提示音期间红色发射灯不亮；
8. PTT 在 SAR 中不会发射；
9. SAR-TEAM 精简构建中确认 `MENU` 不进入 Bandscope，返回路径正常；
10. `EXIT` 可随时退出；
11. 重复进入和退出 SAR 后功能仍正常；
12. 失败时可用已验证的恢复固件重新刷写。

14. PTT 60 秒超时后保持按住不会重新发射，松开后才恢复；

## 安全边界

- 本固件不是认证的生命安全设备，不能作为搜救行动的唯一定位手段；
- dBm 为相对参考，近距离或强信号过载时不是校准功率值；
- 建筑、车辆、山体和金属设施会产生多径，必须换位置交叉测向；
- 频率预设必须由当地任务负责人按法规和行动方案配置；
- 所有新功能先在低功率、短距离条件下测试，再用于野外训练。
