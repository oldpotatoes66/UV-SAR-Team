## 1. 台架安全回归（必测）

- [ ] 正常开机，版本显示 `BH1JID v1.0RC1` 和 `SAR-TEAM`；
- [ ] `F+5` SAR：显示、声音、自动增益、PTT 禁发、EXIT 均正常；
- [ ] 长按 `6` 进入 TEAM：语音接收与人工 PTT 语音发射正常；
- [ ] `F+6`：仅切换发射功率，不进入 TEAM；
- [ ] K1 `F+6`：实际功率变化，有 `TX POWER` 大字反馈；A/B 两行固定显示各自 `L1–L5/M/H`，切换当前 TX VFO 不会误改另一行；
- [ ] K1 TEAM `4` 可循环 L1–L5/M/H，语音、AUTO TX 和 CW 实际功率同步；K5/K6 的 TEAM `4` 键 P1/P2/P3 正常；
- [ ] 短按 `3` 不开启 AUTO TX；长按约 1 秒才开启，并有明显确认；
- [ ] `1/2/4/5` 均有明显确认；K5/K6 的 `4` 循环 P1–P3，K1 的 `4` 循环 L1–L5/M/H；长按 `F` 锁键后配置键无效；
- [ ] 人工 PTT 连续 60 秒后停止发射；保持按住不能重发，松开后恢复；
- [ ] 模拟低电量时显示 `LOW BAT TX OFF`，人工 PTT、AUTO TX、CW 均不能发射，接收和告警仍可用；
- [ ] 失联约 60 秒后三连低音，继续失联时每约 60 秒重复，恢复时双高音；
- [ ] `EXIT` 在等待、语音、轮询、CW 和告警期间都能安全退出；
- [ ] 配置脚本 `show/configure` 复读一致；K5/K6 只能访问 `0x1FF8–0x1FFF`，K1 只能访问虚拟 `0xD000–0xD007`（独立物理扇区 `0x012000`）。
- [ ] 当前机型固件正确：K5/K6 DP32G030 与 K1 PY32F071 二进制没有交叉刷写。
- [ ] `channel_config.py export/import` 在当前机型完成备份、写入和复读验证；若使用 `prune --keep N`，仅保留 1–N 且校准区未改变。
