# UV-SAR-TEAM stable release / 正式版发布

Release bundle: `v1.1`  
UV-K1 firmware: `v1.0`  
UV-K5 / UV-K6 firmware: `v1.1`

## 中文

这是 K1 与 K5/K6 首次同时完成真机验证的稳定版本。主要功能：

- 正常 FM 语音收发与 Yaesu VX-6R/VX-7R/VX-8R ARTS 互通；
- TEAM 链路状态、RSSI、常驻功率、低电保护、60 秒 PTT 超时；
- 失联定时重复声音告警与手电闪光提醒；
- `F+5` SAR 测向与 Bandscope；
- `F+7` 独立测向训练信标：30 秒周期、3 秒信号、呼号 CW、最低训练功率、忙信道避让、低电禁发、30 分钟停止；
- Web 固件刷写、呼号配置和 K1/K6 频道管理。

## English

This is the first stable release validated on both K1 and K5/K6 hardware. Highlights:

- Normal FM voice plus Yaesu VX-6R/VX-7R/VX-8R ARTS interoperability;
- TEAM link status, RSSI, persistent power, low-battery protection, and a 60-second PTT timeout;
- Repeating audible link-loss alerts plus flashlight indication;
- `F+5` SAR direction finding and Bandscope;
- Independent `F+7` direction-finding training beacon with a 30-second cycle, three-second signal, callsign CW, lowest training power, busy-channel avoidance, low-battery blocking, and a 30-minute stop;
- Web firmware flashing, callsign configuration, and K1/K6 channel management.

Use the web tools at <https://sar.trailspud.com/>.

This project is not certified life-safety equipment and must not be the sole rescue communication or location system.
